## 1. 背景与目标

### 1.1 背景

v0.2 迭代（G1~G12）已交付 G1~G7 与 G10，桌面端已具备：自动化测试与 CI、数据备份/恢复、崩溃恢复与日志面板、消息全文检索、首次引导、托盘增强、DAG 任务编排、提示词模板与团队配置。距离"可安心日常使用的桌面工具"还差最后四块拼图：

1. **语义检索未落地**：G8 仅有后端混合检索的局部实现（未提交、IPC 未注册、无前端入口、无真正的向量化 embedding）。
2. **插件无法远程分发**：G9 插件市场（远程源）未实现，插件只能本地导入目录，无法共享与一键安装。
3. **分发闭环不完整**：G11 代码签名与应用内更新未实现；当前只能手动跳转 GitHub 下载页，且安装包未签名（Windows SmartScreen 会拦截）。
4. **网络韧性缺失**：G12 通用 HTTP 代理、请求超时配置、自动重试均未实现；仅存在 headroom 专用代理。

同时探索发现 3 个分发与文档侧缺口（H 系列）：

- **H1 发布自动化**：CI 的 `package` job 仅上传 artifact，打 tag 后不会自动创建 GitHub Release，需人工上传。
- **H2 用户手册缺失**：`docs/` 下无面向终端用户的《用户手册》，新用户只能靠引导页摸索。
- **H3 安装包体验**：安装包无签名说明、无 WebView2 依赖检测与引导、卸载清理无明确约定。

### 1.2 成功标准（可度量）

- 语义查询（如"处理登录超时的代码"）可召回相关文件；无本地 embedding 模型时自动降级为关键词检索，**默认体验不依赖外部模型**。
- 插件市场 MVP：从远程源完成"浏览 → 安装 → 启用 → 停用 → 卸载"全流程，安全约束与本地插件一致。
- 应用内更新：发现新版 → 展示更新说明 → 下载（含进度）→ 校验哈希 → 引导安装；全程有明确状态反馈。
- 通用网络设置：HTTP 代理三态切换即时生效；请求超时可配置；网络失败按策略自动重试或给出明确错误。
- 发布自动化：推送 `v*` tag 后 CI 自动产出 NSIS/MSI 并创建 GitHub Release，附更新说明与校验哈希。

## 3. 功能需求详述

> 优先级：P0 = 本迭代必须交付；P1 = 本迭代应交付；P2 = 尽量交付。
> 所有新增 IPC 命令需同步注册到 `main.rs` 的 `invoke_handler`，并在 `ui/src/lib/ipc.ts` 补充 DTO 与调用封装；中英文案随功能同步补齐。

### 3.1 G8 工作区语义检索升级（P0，收尾）

**需求背景**：F11 关键词检索已上线；G8 的后端混合检索改动已在工作区（`src/ipc/capabilities.rs` 未提交 diff），但未注册、未接前端、无真正的向量召回。

**需求描述**：

1. **收尾现有后端改动**：
   - 将 `workspace_search` 的混合评分（文件名/路径/内容多 token 评分）纳入正式实现，提交当前未提交改动。
   - 注册 `workspace_index_status` IPC 到 `main.rs`，前端补充 DTO 与调用封装。
   - `workspace_index_status` 返回：工作区路径、索引文件数、缓存路径、语义引擎类型（`ollama` / `keyword`）、语义模型名。

2. **向量化能力（可选启用，默认不依赖）**：
   - 检测到本地 Ollama（`localhost:11434`）且已拉取 embedding 模型（如 `bge-m3`、`nomic-embed-text`）时，对查询做向量召回并与关键词召回做 RRF 融合排序。
   - 未检测到 Ollama / 无模型时：**自动降级为关键词模式**，功能与现状一致，不阻塞任何路径。
   - 首次向量索引构建在后台执行，不阻塞 UI；索引缓存存 `~/.wth/index/{workspace_hash}.json`。

3. **索引管理**：
   - 设置页"通用"新增"工作区索引"区块：显示索引状态（文件数/引擎/缓存路径）、"重建索引"按钮、"清除索引"按钮。
   - 诊断页"Agent/工作区"区域展示索引状态摘要（复用 `workspace_index_status`）。

4. **对话内引用**：`@检索` 结果与现有工作区检索合并展示，命中项可直接附加进对话上下文（复用现有"附加文件"交互）。

**验收标准**：

- 无 Ollama 环境下：检索结果与现有 F11 一致或更优，无报错、无阻塞。
- 有 Ollama + embedding 模型时：语义查询能召回"关键词不直接命中但语义相关"的文件。
- 重建索引期间 UI 不卡顿；索引状态数字与磁盘实际一致。

### 3.2 G12 代理与网络韧性（P0）

**需求背景**：目前 agent 请求只支持可选的 headroom 代理；无通用 HTTP 代理设置、超时不可配置、网络失败无重试。

**需求描述**：

1. **设置页新增"网络"区块**（归属"通用"页）：
   - **代理模式**三态：关闭 / 系统代理 / 自定义代理；自定义时填写地址（如 `http://127.0.0.1:7890`）。
   - **请求超时**（秒，默认 15，范围 5~120）：作用于 API 请求与工具调用首响应。
   - **自动重试**开关（默认开）+ 重试次数（默认 2，范围 0~3）：仅对可安全重试的请求生效（连接失败、5xx、超时；不对已产生的工具副作用重试）。
   - 每个字段带标签 + 右侧提示 + 输入框示例占位，与现有设置风格一致。
   - 持久化到 `settings.json`（`network` 子对象：`proxy_mode` / `proxy_url` / `request_timeout_secs` / `retry_enabled` / `retry_max`）。

2. **请求管线改造**（`agent.rs`）：
   - 构造 `reqwest::Client` 时按代理模式配置（自定义代理地址；系统代理交给 `reqwest` 默认行为）。
   - 超时读取设置，替代现有硬编码 15s。
   - 封装重试逻辑：指数退避（1s/2s），失败后按策略重试；重试耗尽后给出明确错误（含"已重试 N 次"）。

3. **连通性自测**：设置页提供"测试连接"按钮，复用 `provider_test` 逻辑，走代理与超时配置。

**验收标准**：

- 配置自定义代理后 API 请求走代理；三态切换即时生效。
- 修改超时后，慢接口按新超时断开并给出清晰提示。
- 模拟断网/5xx：按配置自动重试，最终成功或给出"已重试 N 次后失败"的明确错误。

### 3.3 G9 插件市场（MVP，P1）

**需求背景**：F9 仅支持本地目录插件，无法远程分发与共享。

**需求描述**：

1. **远程源**：插件页新增"市场"标签；默认源为 GitHub Releases 的静态索引 JSON（`Wan-1230/Wide-Thought-Host` 仓库 `plugin-index.json`），支持配置额外源地址。
2. **插件清单**：远程索引返回插件列表（name/description/version/author/download_url/sha256/permissions/verified）。
3. **一键安装**：下载插件 zip → 校验 sha256 → 解压到 `~/.wth/plugins/{name}` → 自动注册技能与 hooks（与 F9 目录约定一致）。
4. **更新与卸载**：本地版本 < 远端版本时显示"更新"；卸载删除目录并清理注册项与开关状态。
5. **安全策略**：
   - 安装前展示权限声明（该插件包含哪些 hooks/命令/技能）；含高风险命令（如执行任意 shell）时需用户二次确认。
   - 非官方源插件标记"未验证"；校验哈希失败拒绝安装并提示。
   - 插件内 hooks 命令执行沿用 F2 约束：不经 shell、10s 超时、失败不阻断。

**验收标准**：

- 从市场源完成浏览 → 安装 → 启用 → 停用 → 卸载全流程。
- 哈希错误 / 源不可达 / 权限不符三种异常场景给出明确提示，不污染现有插件目录。

### 3.4 G11 代码签名与应用内更新闭环（P1）

**需求背景**：安装包未签名（SmartScreen 拦截）；`update_check` 只做版本对比并跳转下载页。

**需求描述**：

1. **签名支持**：
   - `tauri.conf.json` 支持可选证书配置（`signingCertificate` / 环境变量注入密码）。
   - 无证书时打包继续，产物标注"未签名"；设置页"关于"展示当前安装包是否已签名。
   - 文档记录签名步骤（自签名或商业证书），商业证书采购列为可选。

2. **应用内更新闭环**：
   - 新增 IPC `update_download(release)`：下载 GitHub Release 资产（NSIS 安装包）→ 显示进度（`update:progress` 事件）→ 校验发布资产 sha256（取自 Release body 或资产 digest）。
   - 校验通过后：调用安装程序（NSIS 静默安装参数）或提示"更新已就绪，关闭应用后将自动安装"；校验失败则删除下载文件并提示。
   - 设置页"关于"与托盘"检查更新"共用同一流程；下载中断可重试（断点续传为 P2）。

**验收标准**：

- 有/无签名两种打包路径均正常；未签名包在关于页有明确标识。
- 发现新版 → 下载（进度可见）→ 校验 → 安装引导全流程可用；校验失败给出明确错误且不留脏文件。

### 3.5 H1 发布自动化（P1）

**需求背景**：CI `package` job 在 `v*` tag 时打包并上传 artifact，但不会自动创建 GitHub Release。

**需求描述**：

1. 在 `desktop-ci.yml` 的 `package` job 后新增 `release` job（条件：`startsWith(github.ref, 'refs/tags/v')`）：
   - 下载 NSIS/MSI artifact。
   - 计算 sha256 校验和，生成 `sha256sums.txt`。
   - 调用 GitHub API 创建 Release（tag 已存在，复用），上传安装包 + 校验文件 + 变更说明（取自提交信息或维护的手写 `RELEASE_NOTES.md` 片段）。
   - Release 标题含版本号；body 含"更新说明 + 校验哈希 + 安装指引"。
2. 维护 `docs/release-checklist.md`：发版流程（打 tag → CI 自动发布 → 验证安装包）。

**验收标准**：

- 推送 `v0.2.0` tag 后，CI 自动产出 Release，含 NSIS/MSI/校验文件/更新说明，可直接下载安装。
- 无 tag 的普通 push 不触发发布，仅跑测试与构建。

### 3.6 H2 用户手册（P2）

**需求描述**：

1. 新增 `docs/user-guide/` 目录，包含：
   - `getting-started.md`：安装（含 WebView2 依赖说明）、首次启动、选择工作区、配置模型、发起提问。
   - `features.md`：会话、编辑器与 Diff 审查、终端、子智能体委派、工作流、记忆/技能/Hooks/插件、备份恢复、检索。
   - `settings.md`：13 个设置页逐项说明（字段含义、示例、默认值）。
   - `troubleshooting.md`：常见问题（SmartScreen 提示、网络/代理、模型连接失败、数据损坏恢复）。
   - `privacy.md`：数据存储位置、凭据管理、无遥测声明（与根目录 `PRIVACY.md` 保持一致）。
2. 设置页"关于"新增"打开用户手册"入口（本地文档路径）。
3. 内容中英双语（中文为主，英文版与 i18n 同步节奏一致）。

**验收标准**：

- 新用户按手册 10 分钟内可完成安装到首次提问。
- 手册中每个设置项与设置页实际字段一一对应，无"即将上线"占位。

### 3.7 H3 安装包体验完善（P2）

**需求描述**：

1. **WebView2 检测**：NSIS 安装前检测 WebView2 Runtime，缺失时引导下载（链接到微软官方页）或随包附带 bootstrapper（P3 可选）。
2. **卸载清理**：卸载时清理 `%APPDATA%/com.wth.desktop` 中非用户数据（日志、索引缓存、临时文件），保留用户数据（会话/设置/凭据由用户确认是否删除，默认保留）。
3. **版本信息**：安装包文件属性（版本、产品名、描述）与 `tauri.conf.json` 一致；关于页展示完整版本 + 构建时间 + 是否签名。

**验收标准**：

- 无 WebView2 的干净机器安装后给出明确引导而非闪退。
- 卸载后用户数据默认保留，重装后会话与设置仍在。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 语义检索默认不引入额外延迟；向量索引构建后台执行不阻塞 UI；下载更新有进度且不冻结界面 |
| 安全 | 插件市场安装必须哈希校验 + 权限声明确认；更新资产校验哈希；日志持续脱敏（不打印 Key/Token/API 响应体） |
| 稳定性 | 语义引擎/代理/更新任一环节失败一律降级或明确提示，不拖垮主进程；重试仅限安全请求 |
| 兼容性 | Windows 10/11 x64；WebView2 依赖说明；无 Ollama/无网络/无证书三种环境均可用 |
| 可维护性 | 新增 IPC 统一注册 `main.rs`；DTO 与前端同步；P0 功能附测试（Rust 单测或前端单测）；G8 未提交改动先落盘提交 |
| 隐私 | 无遥测、无研究上传、无强制更新（沿用现约定）；插件市场默认源为自建仓库，不含第三方跟踪 |
| 合规 | 商业签名证书为可选采购项；自签名/未签名路径必须有清晰提示 |
