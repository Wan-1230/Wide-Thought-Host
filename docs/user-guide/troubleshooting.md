# 常见问题（Troubleshooting）

## 安装与启动

### SmartScreen 提示"未知发布者"
当前安装包未做代码签名。选择"更多信息 → 仍要运行"。采购商业代码签名证书后此提示会消失。

### 提示缺少 WebView2 Runtime
安装程序会自动引导下载 WebView2（联网环境）。也可手动安装：[微软官方 WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/)。

### 安装后无法启动 / 启动即闪退
1. 检查是否安装了 WebView2 运行时（见上）。
2. 查看诊断页"最近日志"与实时日志（设置 → 诊断）。
3. 在安装目录运行 `wth-desktop.exe`（命令行窗口会显示错误输出）。

## 网络与模型

### 模型连接失败
1. 设置 → 模型与 API → 测试连接，确认 Base URL 与 API Key 正确。
2. 检查网络：设置 → 通用 → 网络 → 代理模式。若使用代理软件，选"自定义"并填写地址，或选"系统代理"。
3. 连接超时过短可调大（范围 5~120 秒）。

### 请求报错 401 / 403
API Key 无效或额度用尽。在设置页重新填写该模型的 API Key（存于 Windows 凭据管理器）。

### 请求偶发失败
应用已支持自动重试（连接失败与 5xx）。若频繁失败，检查网络稳定性或关闭代理重试。

## 功能使用

### @ 检索不到代码
1. 确认已选择工作区（设置 → 通用 或侧边栏工作区选择）。
2. 设置 → 通用 → 工作区索引 → 重建索引。
3. 默认关键词模式即可用；有 Ollama 时会自动升级语义检索。

### 子智能体不响应
子智能体需要在 设置 → 子智能体 中保持启用。委派时 `@` 弹窗中选择子智能体（禁用项置灰）。

### 插件市场打不开
检查网络与市场源（默认 GitHub raw）。也可用"从本地导入"安装目录插件。

### 图片附件无法识别
当前模型不支持视觉时会提示切换支持视觉的模型。图片上限 10MB、文本附件 1MB、单次最多 5 个。

## 数据与恢复

### 会话/设置丢失
- 数据位于 `%APPDATA%/com.wth.desktop` 与 `~/.wth`。
- 若 `sessions.json` 损坏，应用会自动备份为 `.bak` 并回退空态，可从 `.bak` 手工恢复。
- 建议定期 设置 → 通用 → 数据与备份 → 导出备份。

### 如何迁移到新电脑
1. 旧电脑导出备份（`.wthbackup`）与配置（`.json`，不含密钥）。
2. 新电脑安装后：设置 → 数据与备份 → 恢复备份 → 导入配置。
3. 重新输入各模型的 API Key。

### 卸载后数据还在吗
卸载默认保留用户数据（会话、设置）。如需彻底清理，卸载后手动删除 `%APPDATA%/com.wth.desktop` 与 `~/.wth`。

## 其他

### 关闭窗口后应用还在
默认"隐藏到托盘"。设置 → 通用 → 关闭主窗口 可改为"退出应用"。

### 托盘图标不见了
在系统托盘"显示隐藏的图标"中查找。彻底退出：托盘右键 → 退出。

### 快捷键冲突
设置 → 快捷键 中会提示冲突；可录制新组合或"恢复默认"。
