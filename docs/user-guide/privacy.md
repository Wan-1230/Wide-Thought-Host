# 隐私说明

本文档说明 WTH 桌面端的数据存储、网络行为与隐私承诺。与仓库根目录 `PRIVACY.md` 保持一致。

## 核心承诺

- **无遥测**：不采集使用行为、崩溃数据或匿名统计。
- **无研究上传**：不向任何研究项目上传代码或对话。
- **无强制更新**：仅在用户主动点击"检查更新"时访问 GitHub Releases。
- **本地优先**：会话、设置、记忆、技能、插件全部保存在本机。

## 数据存储位置

| 数据 | 位置 |
|---|---|
| 会话与设置 | `%APPDATA%/com.wth.desktop` |
| 记忆 / 技能 / 插件 | `~/.wth`（用户目录）、工作区 `.wth/` |
| 工作区索引缓存 | `%LOCALAPPDATA%` 下的 index 目录（或随工作区） |
| API Key 与凭据 | Windows 凭据管理器（Credential Manager） |
| 下载的更新安装包 | 系统临时目录 `%TEMP%/wth-update` |

## 网络行为

- 模型请求仅发送到你配置的 Base URL（如 Agnes、OpenAI、DeepSeek、Ollama 等）。
- 会话内容不会发送到任何第三方（除你配置的模型端点外）。
- "检查更新"/"下载更新"仅访问 `api.github.com` 与 `github.com` 资产地址。
- 插件市场默认访问本仓库的 `plugin-index.json`；插件安装前展示权限声明，含高风险权限需确认。
- 代理设置（关闭/系统/自定义）仅影响应用自身的 HTTP 请求。

## 日志与脱敏

- 应用日志不打印 API Key、Token 或 API 响应体。
- 诊断页日志面板与导出内容均已脱敏。

## 删除数据

- 删除会话、记忆等操作即时生效。
- 卸载应用默认保留用户数据；彻底清理请手动删除 `%APPDATA%/com.wth.desktop` 与 `~/.wth`。

## 配置导出与共享

- 导出配置（`.json` / `.wthconfig`）**不含 API Key**，以占位符表示；导入后需重新输入凭据。
- 团队配置共享内容不含本地路径与密钥，请勿在模板/系统提示词中写入敏感信息。
