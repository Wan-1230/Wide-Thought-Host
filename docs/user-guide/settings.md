# 设置说明

打开方式：主界面左下角齿轮图标，或快捷键 Ctrl+,。左侧共 13 个设置页。每个字段均带标签、右侧提示与输入示例。

## 通用

### 行为
- **界面语言**：中文 / English。
- **关闭主窗口**：隐藏到托盘（默认）或退出应用。
- **任务完成提示音**：Agent 完成任务时播放提示音。
- **显示系统事件**：聊天中显示系统级事件消息。
- **首次使用引导**：点击"重新运行引导"可再次进入三步引导。

### Agent 行为
- **推理力度**：low / medium / high / max，越高越精确但更慢、更耗 Token。
- **编辑模式**：plan（先给方案再改）/ review（逐块确认）/ auto（自动审批低风险改动）/ yolo（全部自动）。
- **预算上限 (USD)**：累计消耗达到后停止请求；留空不限制。
- **上下文自动压缩**：接近窗口上限时自动压缩早期对话。
- **上下文窗口 (Token)**：当前模型的窗口大小，用于估算压缩阈值（示例：128000）。
- **Token 单价 (USD/百万)**：统一估算单价，用于用量统计（示例：2）。

### 搜索
- **Web 搜索引擎**：Bing / SearXNG / Tavily / Brave / Perplexity。选择 Tavily 时需填写 API Key。

### 网络
- **代理模式**：关闭 / 系统代理 / 自定义代理。
- **代理地址**（自定义时显示）：如 `http://127.0.0.1:7890`。
- **连接超时 (秒)**：建立连接的超时，范围 5~120，示例 15。
- **自动重试**：连接失败或 5xx 时自动重试（4xx 不重试）。
- **重试次数**：0~3，重试间隔按 1s/2s 递增。

### 工作区索引
- 显示工作区路径、已索引文件数、检索模式（语义/关键词）、缓存路径。
- 按钮：重建索引 / 清除索引 / 刷新状态。

### 终端
- **首选 Shell**：自动检测 / PowerShell 7 / Windows PowerShell 5.1 / CMD / WSL Git Bash。

### 数据与备份
- 导出备份（`.wthbackup`）、恢复备份、导出配置（不含密钥）、导入配置。
- 提示词模板：输入框左侧模板入口，支持 `{{workspace}}`、`{{file}}`、`{{language}}` 变量。

### Token 优化
- Headroom 代理开关与端口（可选，启用后 Agent 请求经本地代理转发）。

## 模型与 API

- 添加模型：名称（示例：我的本地模型）、模型 ID（示例：deepseek-chat）、Base URL（示例：https://api.openai.com/v1）、API Key、类型（OpenAI 兼容 / Anthropic）。
- 设为默认 / 测试连接 / 删除。
- 内置 Agnes 模型不在列表展示（默认模型），停用/删除后可用"恢复默认"回到内置。

## 外观

- 主题（浅色/深色）、字体大小（小/中/大）、字体族（系统/无衬线/衬线/自定义）、自定义字体族（示例：`"Microsoft YaHei", "PingFang SC"`）、会话显示密度（标准/紧凑）。

## MCP 与工具

- 添加 MCP 服务器：名称、命令、参数（stdio 类型）；测试连接、删除。
- 启用后其工具以 `mcp__` 前缀注入 Agent。

## 技能

- 浏览本地技能（用户目录与工作区 `.wth/skills`），查看 SKILL.md，启停开关。

## 插件

- **已安装**标签：本地插件列表（启停开关、查看详情、从本地导入目录）。
- **市场**标签：远程插件清单（作者/版本/权限/验证标记），安装/更新/卸载；安装前展示权限声明。
- 插件目录约定：`~/.wth/plugins/{插件名}/plugin.json` + `skills/` + `hooks/`。

## 记忆

- 浏览记忆条目、按标签过滤、新增记忆、删除。
- 对话时按相关性自动注入（最多 20 条）。

## Hooks

- 四类事件：message_sent / agent_response_done / tool_approved / tool_denied。
- 每条 hook：命令、参数、启用开关；执行超时 10s、失败不阻断主流程。

## 子智能体

- 预设：代码审查员、安全审计、文档审查等。
- 编辑名称/描述/系统提示词/模型/允许工具，新增、删除、启停。

## 快捷键

- 动作列表（切换窗口、命令面板、新建会话、打开设置、切换终端、切换主题、发送消息）。
- 点击按键组合即可录制；冲突检测提示；恢复默认。

## 用量

- 今日/本周/累计 Token 与费用；基于真实 usage 数据。

## 诊断

- 环境：WebView2 版本、Git 版本、终端 Shell、OS。
- Agent 核心：默认模型与凭据状态。
- 工作区索引状态。
- 凭据存储读写测试。
- 最近日志（脱敏）+ 实时日志面板（过滤/搜索/导出）。
- 重新运行诊断按钮。

## 关于

- 版本、构建时间、签名状态（未签名时提示 SmartScreen 可能提示未知发布者）。
- 项目主页、检查更新、下载并安装（进度 + SHA-256 校验）、打开安装包所在文件夹。
