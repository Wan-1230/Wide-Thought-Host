# 功能总览

WTH 桌面端是一个多模型、可扩展、隐私优先的 AI 编码代理。本文按模块介绍全部能力。

## 会话与聊天

- 多会话管理：新建、重命名、固定、删除；会话持久化到本机。
- 多轮上下文：历史消息自动回填，长会话自动压缩早期对话为摘要。
- 重新生成 / 从此处分支 / 导出（Markdown、JSON）。
- 会话内消息全文检索（Ctrl+F）与全局消息检索（侧边栏搜索框切换模式）。

## 编辑器与代码审查

- Monaco 代码编辑器：查看与编辑工作区文件。
- Diff 审查：工具修改文件后以 Diff 呈现，可逐块确认/拒绝，支持撤销。
- 编辑模式：Plan / Review / Auto / YOLO 四种审批策略（设置 → 通用 → Agent 行为）。

## 工具与终端

- Agent 工具集：文件读写/编辑/列表/搜索、bash 命令、git、Web 搜索、MCP 工具。
- 内置终端面板：可与 Agent 共享工作区执行命令。
- 审批机制：高风险操作（写文件、执行命令）按策略请求确认。

## 子智能体与多 Agent

- 预设子智能体：代码审查员、安全审计、文档审查等（可编辑、增删、启停）。
- `@` 委派：在输入框输入 `@` 选择子智能体并行处理任务，结果回传主会话。
- 工作流编排（DAG）：内置"审查流水线"模板（代码审查 → 安全审查 → 文档审查 → 汇总），支持顺序/依赖/条件节点，单节点失败可重试。

## 记忆、技能、Hooks 与插件

- 记忆：Agent 可写入长期记忆，对话时按相关性自动注入（最多 20 条）；设置页可浏览/删除。
- 技能：`~/.wth/skills` 下的 SKILL.md 可作为斜杠命令注入系统提示词。
- Hooks：message_sent / agent_response_done / tool_approved / tool_denied 四类生命周期事件，可配置命令回调。
- 插件：`~/.wth/plugins/{插件名}/plugin.json`（含 skills/ 与 hooks/），支持本地导入与远程市场安装；可启停、卸载。

## 工作区检索

- `@` 弹窗支持文件/代码检索：关键词评分（文件名/路径/内容多 token）。
- 检测到本地 Ollama 且已拉取 embedding 模型时自动升级为语义检索，否则保持关键词模式。
- 索引状态可在 设置 → 通用 → 工作区索引 查看与重建/清除。

## 网络与稳定性

- 代理模式：关闭 / 系统代理 / 自定义代理（设置 → 通用 → 网络）。
- 连接超时可配置（5~120 秒）；连接失败与服务端 5xx 自动重试（可关）。
- 崩溃恢复：消息自动保存，异常退出后提示恢复；`sessions.json` 损坏自动归档为 `.bak`。
- 实时日志：诊断页日志面板（级别过滤、关键词搜索、导出）。

## 备份与恢复

- 一键备份全部本地数据为 `.wthbackup`（zip）。
- 恢复前自动备份当前数据；冲突策略可选择。
- 配置导入导出：不含 API Key（凭据需重新输入）；团队配置 `.wthconfig` 可共享子智能体/Hooks/模板。

## 托盘与系统集成

- 托盘菜单：显示/隐藏窗口、新建会话、最近会话（5 个）、快速提问、检查更新、退出。
- 全局快捷键：默认 Alt+W 显示/隐藏等，可在设置页自定义（含冲突检测、恢复默认）。
- 通知：任务完成、子智能体委派完成、发现新版。

## 更新

- 设置 → 关于 → 检查更新：对比 GitHub Releases 版本。
- 发现新版后可应用内下载安装包（进度条 + SHA-256 校验），随后启动安装程序。
