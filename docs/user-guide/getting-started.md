# 快速上手

本文档面向新用户：从安装到完成第一次有效编码辅助，约 10 分钟。

## 1. 安装

- 从 [GitHub Releases](https://github.com/Wan-1230/Wide-Thought-Host/releases) 下载最新 `WTH_Setup_x.y.z.exe`（NSIS）或 `.msi`。
- 双击安装，语言可选简体中文 / English。
- **依赖**：Windows 10/11 x64，需要 WebView2 运行时。若未安装，安装程序会自动引导下载（联网环境）。
- 首次启动会被 SmartScreen 提示"未知发布者"——当前版本未做代码签名，选择"更多信息 → 仍要运行"即可；商业签名证书采购后此提示将消失。

## 2. 首次启动引导

首次启动会进入三步引导：

1. **选择工作区**：选择你日常开发的代码目录（也可"暂不选择"）。
2. **确认模型**：默认内置 Agnes 模型（无需配置即可提问）；也可切换到自定义模型（见下文"配置模型"）。
3. **示例提问**：选择示例问题发起第一次对话。

右上角可"跳过引导"；之后可在 设置 → 通用 → 首次使用引导 → 重新运行引导 再次进入。

## 3. 发起第一次提问

在底部输入框输入问题，例如：

- `分析当前工作区的项目结构`
- `帮我审查 src/main.rs 的代码`

回车发送（或 Ctrl+Enter）。Agent 会自动使用工作区上下文，可调用文件读写、终端、检索等工具。

## 4. 配置模型（可选）

1. 打开 设置 → 模型与 API。
2. 点击"添加模型"，填写名称、模型 ID、Base URL 与 API Key（如 OpenAI、DeepSeek、Ollama 等 OpenAI 兼容端点）。
3. 点击"设为默认"。
4. 内置 Agnes 模型不在列表中展示（默认模型），如需切换回默认请删除或停用自定义默认模型。

## 5. 常用操作

| 操作 | 方式 |
|---|---|
| 新建会话 | Ctrl+N 或侧边栏"+" |
| 全局快捷键 | Alt+W 显示/隐藏窗口 |
| 命令面板 | Ctrl+K |
| 会话内搜索 | Ctrl+F |
| 全文检索 | 侧边栏搜索框切换"消息内容"模式 |
| 附加文件 | 拖拽到输入区，或点击附件按钮 |
| 子智能体委派 | 输入框输入 `@` 选择子智能体 |
| 重新生成 | 消息右键 → 重新生成 |
| 从此处分支 | 消息右键 → 从此处分支 |

## 6. 数据与隐私

- 所有数据保存在本机 `%APPDATA%/com.wth.desktop`（会话、设置、记忆）与 `~/.wth`（技能、插件、记忆）。
- API Key 仅存 Windows 凭据管理器，不写入配置文件。
- 应用无遥测、无研究上传、无强制更新。
- 定期使用 设置 → 通用 → 数据与备份 → 导出备份 保护数据。
